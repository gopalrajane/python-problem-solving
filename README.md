# Python Problem Solving

A collection of Python exercises organized by day and topic to practise programming fundamentals and logical problem solving.

## Topics

- Input, output, variables, and data types
- Conditions and loops
- Strings and string operations
- Lists, tuples, and sets
- Dictionaries
- Functions
- Basic programming exercises

## Structure

Each day has its own folder containing numbered practice files.

```text
python-problem-solving/
├── Day01_.../
│   ├── q1.py
│   ├── q2.py
│   └── q3.py
├── Day02_.../
└── README.md
```

## Run

Use Python 3 to run an exercise:

```bash
python Day01_Input_and_Basics/q1.py
```
